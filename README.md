# Codespace Hello-World Demo

Wenn du im Codespace noch keinen Code siehst, mache zuerst ein Update vom Remote-Branch:

```bash
git pull
```

Danach solltest du mindestens diese Datei sehen:

- `index.html`

## Vorschau im Browser starten

Im Codespace-Terminal:

```bash
python -m http.server 3000
```

Dann in VS Code Web:

1. **Ports** öffnen
2. Port **3000** auswählen
3. **Open in Browser** klicken

## Alternative mit Node.js

Falls du lieber `npm start` nutzt:

```bash
npm install
npm start
```
